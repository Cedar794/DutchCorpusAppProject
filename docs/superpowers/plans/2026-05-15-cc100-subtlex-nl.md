# CC-100 Dutch SUBTLEX-Style Frequency Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a resumable non-LLM pipeline that turns Dutch CC-100 text into SUBTLEX-NL-style frequency tables.

**Architecture:** Stream the XZ corpus, annotate batches with Dutch NLP tooling, aggregate counts into shard files, merge deterministic outputs, and export CSV/XLSX plus metadata and QC reports.

**Tech Stack:** Python 3, standard library streaming/counting, native Frog/Tadpole-family Dutch NLP tooling, SQLite for merges, `openpyxl` for reference workbook inspection and optional XLSX export.
