# Woordhuis · 词典界面

原生 HTML/CSS/JavaScript，无构建步骤；入口为 `site/index.html`、`css/dictionary.css` 和 `js/dictionary.js`。原 API 控制台文件保留供回归测试，用户入口不再加载。

首页只有一个查询框与「查词 / 按意思找词」模式切换。普通查词命中后直接加载词条详情；输入至少一个字符、停止输入后请求联想，支持上下键、回车、Escape、鼠标和触屏选择，处理中文输入法合成。联想仅用于查词模式，有节流、取消过时响应和内存缓存。

语义查询仅显式提交时调用模型。地址刷新或切换模式不自动调用模型；同页后退到语义结果使用内存快照。模型密钥与预算始终由服务端管理。HTTP 429 按 Retry-After 暂停查询，没有自动重试。

词条展示译义、荷文定义、英文解释与义项例句；更多释义/例句显式分页。词形、表达、语料和来源许可渐进展开。URL 保留查询与词条链接，支持浏览器前进后退；所有词库内容以文本节点渲染。

线上预览：http://39.106.117.93/ 。云端部署与私有 SSH 隧道说明见 `../docs/cloud-migration.md`。本地数据已迁云，不需要重新启动本地数据库。

回放调试可以启动 `api-contract/mock_server.py`，同时以 HTTP 提供 `site/`，使用 `?api=http://127.0.0.1:8799` 指向 mock。回放不产生模型费用，响应仅覆盖录制场景。
