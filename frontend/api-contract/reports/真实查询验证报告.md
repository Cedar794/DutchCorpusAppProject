# 真实查询改写验证报告

## 结论

北京地域 Qwen3.7-Flash 权限及真实调用已验证。使用 rewrite-v2，完成 **14 条中英荷输入的原文/改写对照，共 28 次语义请求**；另有 4 次校准请求和 5 次故障回退请求。全部真实模型调用都在独立的 **1 元累计及每日预算**内，保留默认单 IP 限流。

这批样本**没有证明改写提高排序效果**：13 条带助手预设可接受词头集合的查询，12 条排名不变、1 条下降、没有改善。改写的主要作用是去掉客套话。1 次真实 Flash 超时成功回退原文，其余 13 次收到有效改写结果，其中 5 次改变文字、8 次保持原文。不能把本轮连通成功当作整体准确率验收。

中文网页描述的 website 两组均第 4；不能归因于向量缺失。无关/恶意输入样本被当作文本检索，没有发现真实 Key 值或词库写入，但接口没有无关输入拒答阈值，因此仍返回了相关性有限的词。这不能推广为完整的注入安全评测。

## 校准中发现并修正的问题

最初 rewrite-v1 的两条真实校准出现了不必要的荷兰语翻译及词性标签丢失。随后增加明确的保持原语言要求和中英荷示例，并对中文转为纯非中文结果增加保守回退。rewrite-v2 两条复测通过后才进行上述 14 条成对测试。四条校准响应全部保留，未混入最终效果指标。

## 回退与限流

1. 真实 NL 轮椅描述超过 1,200 ms 改写截止时间，接口以原文继续真实 v4 检索，返回 HTTP 200。
2. 另对超时、403、429、无效 JSON、约束丢失进行可控故障注入，五种情形均回退原文并完成真实 embedding 检索，返回 HTTP 200。这五种注入不代表供应商实际出现了权限/配额故障。
3. 默认单 IP 总额度 60 次/分钟、语义 10 次/分钟、10 秒突发 10 次保持原值。真实模型请求按同一测试 IP 串行节流，观察到任意 60 秒最多 10 次付费语义请求。突发测试实际捕获 429 与 Retry-After，没有发起模型调用。
4. 词条不存在、义项不存在、参数越界、空白查询、过大请求体及语义功能关闭，分别录制 404/422/413/503；连同正常详情、词形、多义项、例句、表达共 69 份实际响应。

## 费用

真实供应商 HTTP 尝试 55 次：Flash 18 次、v4 37 次。54 次有确认 usage，按北京公开原价折算为 **0.0014623 元**；另有 1 次超时请求保留最大预留，**含预留的费用上界 0.0033055 元，小于 1 元**。不假设免费额度、缓存折扣，也未独立核对最终账单扣费。账本持续保留，不因重启清零；未复用此前全量 embedding 的 5 元预算。

## 前端交付

OpenAPI、全部字段说明、TypeScript 类型和 fetch 客户端、实际响应及离线回放服务随包交付。provenance 明确区分真实模型结果、真实数据库请求、受控配置和注入故障。前端可直接设计加载、纠错、空态、多义项分页、例句展开、改写回退、429 倒计时及服务暂不可用等状态。所有响应值来自本轮运行，不为页面效果捏造结果。

真实后端仍未公网部署。当前建议保持可回退和可单独关闭的改写功能，并扩大独立复核样本后再决定排序优化；本轮遵照用户选择保留直接 Flash 改写流程，没有新增独立意图识别模型。
