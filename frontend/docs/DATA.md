## 2. 接口字段 → 界面口径

| 字段 | 界面怎么用 | 明确不做的事 |
| --- | --- | --- |
| `score` | 写作「排序分」，条形按最大值归一 | 不写成「匹配度 %」「准确率」 |
| `confidence` | 写作「置信度 %」，tooltip 说明是启发式 | 不当成校准概率 |
| `level` (1–4) | L1–L4 票据，颜色编码 | 不叫 CEFR；`cefr_level` 单独显示且可为空 |
| `frequency` | 「语料频次」+ 千分位 | 不当成百分比或学习人数 |
| `review_status` | 绿 / 黄 / 空心灰点 + 「已审核 / 待复核 / 未复核」 | 不统一标成「已审校」 |
| `article` / `gender` | **有值才显示** | 不为 `de/het` 猜一个 |
| `needs_review` | 词头 / 词性 / 词形的待复核票据 | 不写成「有错」 |
| `sense_disambiguated:false` | 语料例句独立成区并写明显式警告 | 不把例句挂到某个义项下 |
| `matched_reason` | 可展开的「排序构成」，注明加权分可 > 1 | 不当概率解释 |
| `query_rewrite.status` | 回退类状态显示「已按原描述搜索」 | 不隐藏改写失败 |
| `form.morph_features` | 保留原始键值，不做形态学推断 | 不从词形反推「复数/过去式」标签 |
| `word_family` | 只显示词族名与中心 ID | 不列出接口没给的成员 |

### 没做的事

- **没有音标**：接口不提供 IPA，界面一个都不编。语言指南讲的是「拼写→读音」的规律（`ij` 读 `[ɛi]`），标注为编辑性说明。
- **没有机器翻译兜底**：例句没有译文时留空，不现场调模型。
- **没有自动补全冠词、词性、变位表**。

## 4. 我们观察到的源数据问题（未修改，只做展示层归并）

录制里确实存在这些问题，界面**照实显示**，只在「纯展示重复」时归并：

| 现象 | 例子 | 界面处理 |
| --- | --- | --- |
| 译文中荷混排 | `ontdekken` 义项 1：「找到 wat verborgen is」；「某事 找到 或 leren waarvan…」 | 原样显示，不做润色；这也是「未复核」状态存在的理由 |
| 同一句语料挂在多个词性下 | `goed` 的语料区同一句出现 3 次（`lemma_pos_entry_id` / `form_id` 不同） | 合并为一行，右侧标「3 处归属」，区块下说明合并数 |
| 义项 `sense_no` 在不同词性下重复 | `huis` 有多个 `sense_no = 1` 的义项 | 页面序号改为当前页序号 01…；`sense_no` 不再重复展示 |
| 词性来源重复 | `N` 与 `NOUN` 都映射到 `noun` | 词性导航按 `app_pos` 去重，tooltip 保留 `N / NOUN` |
| 义项译文语义偏移 | `zeggen` 主义项译文为「词」 | 原样显示 |
| 词形同一串出现多次 | `afzetten` 作为标准词形出现 2 次（名/动） | 按词形合并，`×N` 表示来源数 |

**原则**：可以为了可读性合并「完全相同的东西」，但绝不改写、润色或补全内容。

## 5. 离线回放的边界

- 只回放 69 个录制请求；其它请求返回 **mock 专用 501**，界面显示「这次请求没有录制」，与真实错误分开。
- 分页切片（见 `INTERACTION.md` §10）只在同路径已录制页内取子区间，顺序不变、条目不增。
- 演示模式的数据是**快照**：真实后端尚未公网部署，词库与模型都在演进，页面数据不代表当前线上状态。
