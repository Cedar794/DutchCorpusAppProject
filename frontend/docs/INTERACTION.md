# 交互规格 · Woordhuis

接口合同版本 2026-10-23。本文只描述**界面行为**；字段含义以 `api-contract/API_SPEC.md` 为准。

---

## 0. 三条链路不混

```
查词       输入 ──▶ GET /suggest（防抖联想）──▶ GET /lookup ──▶ 词条
按意思     输入 ──▶ （不联想）──▶ 显式提交 ──▶ POST /semantic-search ──▶ 结果页 ──▶ 词条
读词条     词条 ──▶ GET /entries/{id}（四组独立分页）──▶ GET /senses/{id}/examples（按需）
```

- 联想**只**服务查词（`/suggest` 便宜、可缓存），语义链路不绑按键。
- 普通查词**不会**自动降级成付费语义查询；界面上也没有「自动判断意图」的入口。
- 语义结果里的每条卡片**不预取详情**——按需求额度，点开再取。

## 1. 搜索框（首页 / 结果页复用）

组件：`WH.ui.search()`，ARIA combobox。

| 行为 | 规格 |
| --- | --- |
| 模式切换 | 两个 tab（查词 / 按意思找词）。在首页切换是**原地重绘**，保留已输入文字并回焦，不跳页 |
| 联想触发 | 查词模式、≥2 字符、**320ms 防抖** |
| 联想缓存 | 前缀 → 结果 Map；重复前缀直接命中，不打网络 |
| 过时响应 | 每次请求带自增 `seq` + `AbortController`；旧响应到达即丢弃 |
| 429 | 联想区内联提示「联想请求已受限流（429）」，不影响回车提交 |
| 键盘 | `↑` `↓` 移动高亮（同步 `aria-activedescendant`）、`↵` 打开高亮项或提交、`Esc` 关闭 |
| 空候选 | 「没有以「x」开头的词头。按 ↵ 仍然可以完整查一次」 |
| 焦点 | `⌘K` / `Ctrl K` / `/` 全局聚焦；离开页面后聚焦会先回首页再聚焦 |

提交行为：

- 查词 → `#/zoeken?q=`
- 按意思 → `#/betekenis?q=`
- 两者都会写入「最近查询」（最多 6 条，localStorage）。

## 2. 查词结果页 `#/zoeken`

`GET /lookup?q=` 回来后按 `best_match` 分支——**只**看它是不是 `null`。

| 响应 | 界面 |
| --- | --- |
| `best_match` 非空 | `history.replaceState` 直接进 `#/woord/{id}?q=&form=&mt=`。因为替换而不是压栈，返回键回到首页搜索框，不会看到闪一下的结果页 |
| `best_match=null` + `did_you_mean` 非空 | 结果页列出候选：词头、命中词形（`← huishou`）、`match_type` 中文标签、`level`、`score`、`confidence`。顶部超短警示条 **「未命中。下列为纠错与近似候选。」**，右上角 hint 直接写 `best_match = null` |
| 两者都空 | 独立空态：词库没有这个词 + 「按意思找词」出口 |
| 429 / 503 / 5xx | 状态页 + 重试（429 带倒计时） |

`match_type`、`score`、`confidence` 只作辅助说明，**不用于分支**，也不显示成百分比。

## 3. 按意思找词 `#/betekenis`

- 进入页面即发 **一次** `POST /semantic-search`（`limit=10, include_related=true`）。同一 query 在本次会话内缓存，前进/后退不会重复计费。
- **不自动重试**：失败只给「重试」按钮（会再花一次额度，按钮文案直接写明）。
- 等待态：不确定进度条 + 秒表 + 阶段文案「改写描述 → 向量检索」。
- 结果页结构：

```
[模式标签]                                    [10 个主结果 · 1 个关联词]
「原描述」
[说明：按排序分排列；没有低相关性拒答阈值]
┌ 改写披露 ─ 改写状态 / 用于检索 / 原输入 ────────────┐
[主结果]  按排序分                            不是准确率
 01  词头 L1 / 命中义项中文 / 英文 / 荷语释义 / ▸排序构成 / score 条
 …
[关联词]  关系扩展 · 独立区块（不是语义命中）
```

- **改写披露**：`query_rewrite.query` 与原文不同才显示「用于检索」；`status` 非 `rewritten/unchanged` 时插入警示「改写没成功，已按原描述搜索」。
- **排序构成**：`<details>` 展开显示 `semantic_score / frequency_boost / level_boost`，并注明「最终 score 是加权排序分，可能大于 1，不是准确率百分比」。
- **关联词**独立成区，eyebrow 直接写「关系扩展 · 非语义命中」。
- 空结果 → 空态（不声称「词库没有这个概念」，只说没检索到）。
- 头部只保留：模式标签 + `按排序分` + 结果计数 + 原描述，没有说明性段落。

## 4. 词条页 `#/woord/:id`

### 4.1 首屏

- 词头（IJ 双字母带细下划线）+ 主义项译文 + 票据行（等级 / CEFR / 学术词 / 词头复核状态 / 统一词性）。
- 元数据条：义项、词形、语料例句、表达、语料频次、词族、来源数。
- 词性导航：按 `app_pos` **去重**，tooltip 保留来源 `pos`（`N / NOUN`）；点击按 `app_pos` 过滤义项，再点取消（保留 `lemma_pos_entry_id` 与义项的对应关系，不删任何义项）。
- 匹配横幅：从 `huizen` 进来显示「你查的是 huizen → 定位到词头 huis（词形完全匹配）」；从语义结果进来显示「已标出检索命中到的那条义项」+ 原描述截断 40 字。

### 4.2 吸附锚点

`释义 / 语料例句 / 词形 / 表达 / 来源`，`IntersectionObserver` 滚动高亮（`rootMargin: -20% 0 -70% 0`），点击平滑滚动。深链 `?to=betekenis-12960` 会在渲染后滚到该义项。

### 4.3 义项

- 序号是**当前页序号**（01…），不冒充 `sense_no`；`sense_no` 不再重复显示，避免一个词出现多个 01。
- 首屏义项卡带 26ms 间隔的入场位移，最多叠加 9 档。
- 标签：`核心` / `主要` / `domain` / `register` / 审核状态。
- 有译文列表里非中英语言时才补票据（语言 + gloss）。
- 例句：接口给的最多 3 条预览；`examples.has_more` 时按钮「还有 N 条例句」→ `GET /senses/{id}/examples?offset=0&limit=20`，替换为完整列表并标明请求路径。
- 底部：来源名 + 置信度（标注「启发式分数，不是概率」）+ 复制义项链接。

### 4.4 四组独立分页

| 组 | 参数前缀 | 默认页大小 | 合并规则 |
| --- | --- | --- | --- |
| 义项 | `sense_` | 20 | 按 `sense_id` 去重后 append |
| 词形 | `form_` | 50 | 按 `form_id` 去重后 append |
| 语料例句 | `example_` | 5 | 按 `lemma_example_id` 去重后 append |
| 表达 | `expression_` | 20 | 同上 |

**关键**：`GET /entries/{id}` 每次都会返回全部四组；加载某组下一页时，**忽略**响应中其它组的数据，避免把已读内容冲回第一页。结束条件统一用 `has_more === false`。

### 4.5 语义命中定位

`?sense=1991` 进来时：

1. 若义项在第一页 → 直接 `scrollIntoView({block:'center'})` + `.sense--target` 高亮。
2. 否则按 `next_offset` 循环取下一页（最多 3 页），找到即停。
3. 仍找不到 → 保留第一页，横幅已说明「匹配到的义项」；不假装成功。

### 4.6 语料例句

- 独立区块 + 显著提示：`sense_disambiguated = false`，**不挂到任何义项下**。
- 同一句文本挂在多个词性/词形下时**合并显示**，右侧标「N 处归属」，区块下只留一行「合并了 N 条重复归属」。
- 该组没有独立译文（接口如此），所以不显示翻译位。

### 4.7 词形

- 按**词形字符串合并**：`同一串字母可能同时是标准词形、字幕语料词形和 CC100 词形`，重复列出会制造噪音；合并后 `×N` 表示来源数。
- 筛选 chip：全部 / 标准词形 / 语料词形；带搜索框（220ms 防抖，重绘后回焦并恢复光标）。
- 点击任意词形复制到剪贴板，toast 反馈。

### 4.8 表达

按 `entry_kind` 分四组，标题各不相同，**不统称「固定搭配」**：

| entry_kind | 标题 | 说明 |
| --- | --- | --- |
| `lexical_expression` | 词汇表达 | 意义不等于各词相加的固定单位 |
| `usage_construction` | 语法构式 | 结构在特定语境中的用法 |
| `definition_note` | 释义说明 | 帮助理解义项的说明性短语 |
| `usage_example` | 用例 | 一次性搭配 |

### 4.9 来源

按接口返回顺序列出：名称 + 署名、来源类型中文标签、许可、版本、来源页链接。字段为空就不补。

### 4.10 侧栏

1. **词族** — 词族名与中心 ID；一行说明「无成员列表，需逐个查」。
2. **标注透明** — 已加载条数 + 审核分布条 + 四行计数；脚注一行「置信度是启发式分数，非概率」。
3. **语言指南 · 本词** — 根据词头与词形推断（IJ / 可分动词 / 指小词），每条不超过一行，注明「词形推断，非接口字段」。
4. **释义显示** — 中文 / English / Nederlands 三档。

## 5. 释义语言切换

全局偏好（localStorage），影响：主义项译文、词条页词头旁的释义、统一词性标签、词形显示标签、例句译文（`nl` 档退回英文译文）。

**荷兰语原释义 `definition_nl` 永远保留**——切到中文也不隐藏原文。

## 6. 错误与状态矩阵

| 状态 | 触发 | 界面 |
| --- | --- | --- |
| 加载 | 请求中 | 与真实布局同形的骨架（词条 / 结果两套），不用转圈 |
| 200 + 空 | 空数组 / null | 区分「没命中但有点子」与「真的没有」 |
| 404 | 词条/义项不存在或未公开 | 状态页「词条不存在或未公开」+ 返回查词 |
| 413 | 请求体 > 8 KiB | 提示缩短描述 |
| 422 | 参数不合法 | 列出 `loc › msg`（`detail` 为数组时逐条；为字符串时直接显示） |
| 429 | 限流 | 倒计时按钮（`Retry-After`，无该头时默认 30s）+ 「已加载内容仍可阅读」 |
| 503 | 服务 / 模型 / 预算不可用 | 提示稍后重试；**语义未开启**时额外给「改用普通查词」 |
| 501（仅离线回放） | 未录制的请求 | **与真实错误分开**：「这次请求没有录制」，并说明 mock 专用 |
| 网络 / 超时 | fetch 失败 / 30s | 分别提示；超时文案包含「不自动重试 ≠ 未产生费用」 |

状态页统一结构：瓷砖托板图标 → 代码（mono）→ 标题 → 说明 → 动作。不弹窗。

## 7. 限流与额度

接口：单 IP 60 次/分钟、10 秒最多 10 次；语义另限 10 次/分钟；404/422 也计额度。

前端策略：

1. 联想防抖 320ms + 前缀缓存 + 丢弃过时响应 → 正常输入不会打满突发额度。
2. 语义只在显式提交时请求一次，无自动重试、无预取、无轮询。
3. 429 时暂停提交并倒计时；不清空已有内容。
4. 不通过并发请求「绕过」额度（文档明确说这不会得到新额度）。

## 8. 键盘与无障碍

| 键 | 行为 |
| --- | --- |
| `⌘K` / `Ctrl K` / `/` | 聚焦搜索（非输入态） |
| `↑` `↓` | 联想列表移动，滚动到可视区 |
| `↵` | 打开高亮候选 / 提交查询 |
| `Esc` | 关闭联想、关闭弹层 |
| `Tab` | 正常顺序；首个可聚焦元素是「跳到主内容」 |

- 搜索框 `role=combobox`、`aria-expanded`、`aria-controls`、`aria-activedescendant` 全部随状态更新；候选 `role=option` + `aria-selected`。
- 路由切换后聚焦 `#main`（`tabindex=-1`），读屏能感知页面更换；`document.title` 随词头更新。
- 对比度：正文 `--ink` 于 `--paper` ≈ 15:1；次级文字 `--ink-3` ≈ 4.6:1；钴蓝按钮白字 ≈ 9:1。
- 深色模式与浅色模式共用同一套语义 token。
- 尊重 `prefers-reduced-motion: reduce`。
- 打印样式：隐藏导航 / 侧栏 / 交互控件，义项 `break-inside: avoid`。

## 10. 离线回放的适配器行为

`js/api.js` 的 demo 适配器复刻 `mock_server.py` 的匹配：方法 + 路径 + 参数（含默认值）+ 请求体完全一致。

额外一条：分页请求没有精确录制时，在同路径、已录制的页里**按 offset 切片**，用录制的 `total` 重算 `has_more` / `next_offset`；只返回录制中存在、顺序未变的条目。未覆盖的区间仍返回 mock 专用 501 → 界面显示「这次请求没有录制」。

这样做的原因：`afzetten` 的录制页大小是 7（共 33 义项），按合同默认 20 去请求必然落空；切片让演示能连续读两页，又不伪造任何条目。

## 11. 动效规格

原则：**不阻塞首屏、不延迟操作、尊重 `prefers-reduced-motion`**。全部时长 ≤ 420ms。

| 动效 | 触发 | 参数 |
| --- | --- | --- |
| 页面入场 | 路由切换 | `#main.is-entering > *` 位移 8px + 淡入，320ms `cubic-bezier(.16,1,.3,1)` |
| 列表错峰 | 词砖墙、语义结果、首屏义项卡 | 每项 26ms 递增，最多 9 档（`min(--i, 9)`），单项 360ms |
| 联想下拉 | 打开候选 | 自上而下 6px + 淡入，160ms；空间不足翻转到输入框上方时改为纯淡入 |
| 主题切换 | 点月亮/太阳 | View Transitions 径向裁切（从点击点扩散 420ms）；不支持时直接切换 |
| 词砖悬停 | hover / focus | 上浮 2px；圆章旋转 45° 并放大 4%，450ms |
| 词形项 | hover | 词向左移 2px，背景转浅钴蓝 |
| 按钮 | active | 下压 1px；图标按钮缩放 0.94 |
| 载入中 | 分页按钮 | 12px 旋转环 + 「载入中」 |
| 复制反馈 | 复制成功 | 图标换勾 + 「已复制」，1.4s 后复位 |
| 倒计时 | 429 | 数字每 1s 呼吸（opacity .45 ↔ 1） |
| 骨架屏 | 首次请求 | 220% 宽度高光扫过，1.4s 循环 |
| 弹层 | 语言指南 | 0.985 → 1 缩放 + 淡入 220ms；遮罩同步淡入 |

`prefers-reduced-motion: reduce` 时：以上动画全部 `animation: none`，悬停位移归零，View Transition 回退为瞬时切换。
