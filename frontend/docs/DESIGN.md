# 设计说明 · Woordhuis

> 这份文档解释「为什么长成这样」，以及每个来自荷兰的元素到底在承担什么功能。

---

## 1. 一句话概念

**一家住着词条的运河屋：白瓷做墙，钴蓝画线，每一格都是一块代尔夫特瓷砖。**

- 词条是房子（huis），义项是房间（kamer）——首页的赫夫标题就是这个隐喻：*一个词，不止一间屋子*。
- 荷兰语里 `woordenschat` 直译是「词的宝藏」，界面用它当词汇区的栏目名。
- 视觉语言只取两样荷兰的东西：**Delfts blauw（代尔夫特蓝）** 的钴蓝＋白瓷，和 **De Stijl / Total Design** 的硬网格。

## 2. 配色

| Token | 色值 | 用途 |
| --- | --- | --- |
| `--kobalt` | `#1D3F73` | 主色。链接、按钮、选中态、瓷砖反转色 |
| `--kobalt-deep` | `#0E2748` | 悬停与深衬 |
| `--kobalt-soft` | `#E8EEF7` | 语义命中的浅底、义项序号底 |
| `--kobalt-line` | `#B9CBE4` | 瓷砖角标、细线 |
| `--paper` | `#F7F5EF` | 页面底色（暖白瓷） |
| `--paper-2` | `#FFFEFB` | 卡片 / 词砖 |
| `--ink` | `#14171C` | 正文 |
| `--rood` | `#B32B20` | L2 分级、错误强调 |
| `--geel` | `#D99B1E` | L3、待复核、例句高亮 |
| `--oranje` | `#C14E0C` | 限流倒计时 |

代尔夫特陶是**锡釉**：白釉底 + 氧化钴绘画，1600 年前后在代尔夫特兴起，成为荷兰最广为人知的视觉符号（[Delftware](https://en.wikipedia.org/wiki/Delftware)）。界面把它拆成两件事：**白瓷底**（页面、卡片、词砖）和**钴蓝线**（1px 规则、角标、图形）。没有渐变光晕，没有 16px 圆角——圆角是当代 SaaS 的语法，瓷砖是直角拼缝的语法。

颜色是**有含义才出现**：

- L1 钴蓝 · L2 红 · L3 黄 · L4 黑（项目分级 1–4，不是 CEFR；四个等级正好用 De Stijl 三原色＋黑）。
- 绿 / 黄 / 空心灰：已审核 / 待复核 / 未复核。**未复核用空心灰而不是红色**——未复核是中性事实，不是错误。

深色模式叫 *Nachtblauw*：钴蓝翻成瓷蓝，纸色翻成夜航蓝，只换 token，不改布局。

## 3. 网格与排版

12 栏硬网格，4px 基准节奏，最大宽度 1240px。词条页是 **8 栏正文 + 4 栏侧栏**，侧栏在宽屏吸附。

字族四支，全部 SIL OFL，本地加载（不请求 CDN）：

| 角色 | 字体 | 理由 |
| --- | --- | --- |
| 词头 / 标题 | **Fraunces**（可变，`opsz 144`） | 高对比衬线，像瓷器上的手写标记；`WONK 0` 保持理性 |
| 释义 / 例句 | **Source Serif 4** | 长文阅读，接近纸质词典 |
| 界面 | **Inter** | 中性、字重齐全、小字号清楚 |
| 数字 / 标签 / 代码 | **IBM Plex Mono** | 分级、页码、`sense_offset`、`GET /entries/138` 这类实现细节 |

中文回落到系统宋体（Songti SC / Noto Serif CJK），于是中文大标题与 Fraunces 词头共享衬线气质；正文中文也用宋体，读起来像书。

**版式判断**：小 word 不用大色块包裹；等级、状态、计数一律做成 mono 小票据（`.ticket`），像印章而不是徽章。

## 4. 荷兰语言元素：六个真的用得上的

界面里的荷兰语元素不是贴纸，每一个都对应一个解释入口（`Taalwijzer`，六条卡片）。

### 4.1 IJ 是一个字母

荷兰语的 `ij` 是二合字母，读 `[ɛi]`；**词首大写时两个字母一起大写**（`IJsselmeer`、`IJmuiden`），排序位置等同 `y`（[IJ (digraph)](https://en.wikipedia.org/wiki/IJ_(digraph))）。

界面实现：`WH.withDigraph()` 会给词头里出现的 `ij/IJ/ĳ/Ĳ` 包一层 `.digraph-ij`，渲染一条细下划线——这是一个**排版提示**，不是装饰。词头含 IJ 时，侧栏「语言指南 · 本词」会额外解释这条规则。

### 4.2 一个词，多间屋子

`huis` 四个字母，13 个义项、34 个词形；`afzetten` 15 个词形、33 个义项。词条页的义项编号是方瓷砖（`.sense__no`），一格格往下排——正好是「一间间房间」。

### 4.3 de / het

荷兰语名词分通性与中性。接口的 `article` / `gender` 目前多为 `null`，所以界面**只在有值时才显示**，没有就在侧栏解释「词条没收录，就留空——不猜」。这是全站最典型的一条原则：**缺数据时不填**。

### 4.4 可分动词

`afzetten` 的 `af-` 在句子里会跑到句尾（`ik zet het af`），过去分词把 `ge-` 夹在中间（`afgezet`）。界面从词形本身推断：前缀 + 词形证据（`afgezet`、`afzet`），命中时在侧栏给一张卡，并明确写「这是根据词形做的推断，不是接口字段」。

### 4.5 指小词 -je

`-je / -tje / -pje / -etje` 几乎可以加在任何名词上，不只表示「小」，也常表示随意、亲昵、轻描淡写。词头以指小后缀结尾时提示这条。

### 4.6 拼写会变

`huis → huizen`（长元音补字母）、`reizen → reis`（s/z、f/v 交替）。语言指南里用真实词形成对举例，避免把「形态标签」当成接口没给的数据来编。

### 4.7 文案：Doe maar gewoon

荷兰人自己也常说 *Doe maar gewoon, dan doe je al gek genoeg*（正常一点就行，装怪已经够多了）。它被当成文案原则：**只写功能文本**——状态、数值、下一步动作。判断与依据不铺陈在页面里，压缩成一行 hint（如 `best_match = null`）或 tooltip，完整解释留给「数据与方法」和 docs。

页脚格言 *Al doende leert men*（边做边学）。

## 5. 图形

全部手绘 SVG，无第三方素材：

- **运河屋山墙（`SKYLINE`）**：trapgevel（阶梯）、klokgevel（钟形）、halsgevel（颈形）、tuitgevel（尖顶）、lijstgevel（檐口）五种，8 栋不同高度。首页 hero 底部一条 1.6px 线稿，像运河边的天际线。
- **瓷砖角标**：`.tegel::before` 用 8 段 1px 渐变画四角 L 形拼缝。
- **词砖徽章**：菱形 + 圆心的代尔夫特式圆章（`medallion`），悬停时随砖一起翻成钴蓝。
- **风车**：空态与 503 的图案，装在 92×92 的「瓷砖托板」里，而不是散落在页面。
- **山墙 logo**：24×24 的尖顶小屋，屋顶尖上一道红点（呼应荷兰国旗的 red-white-blue 三色，只在页头 kicker 的小旗里完整出现）。

## 6. 布局决策

- **首页**：左 7 栏标题 + 搜索，右 5 栏「真实词条样张」（`huis` 的前六个义项，底部 `entries/138` 角标）。没有说明性段落——样张本身就是说明书。
- **词砖墙**：5×2，每格是录过响应的真实词条；右上角 L1、中间圆章、底部义项数；悬停时砖变钴蓝、义项数换成来源里的第一条荷兰语释义。
- **Note 条**：首页底部三枚 mono 键（`score` / `corpus` / `offline`）各带一句不超过 12 字的口径提示，替代原来的四栏特性介绍。
- **数据与方法**：改成参考手册体——键值表 + 数据表 + 四行「不做的事」，删掉长篇论述（论述在 `docs/`）。
- **词条页**：词头 + 票据行 + 一张横贯的元数据条（义项 / 词形 / 语料 / 表达 / 频次 / 词族 / 来源），下面吸附式锚点导航。正文按「释义 → 语料 → 词形 → 表达 → 来源」排列，与接口文档描述的词条结构一致。
- **结果页**：语义结果每行 = 序号（mono）+ 词头（Fraunces）+ 等级票据 + 命中义项 + 三条分数构成（可展开）+ 右侧排序分条。
- **状态页**：不弹 modal，不塞 toast 了事——错误、空态、未录制各成一页，带 `Retry-After` 倒计时、可继续浏览的提示。

## 7. 动效

一套小而统一的运动语汇，全部 ≤ 420ms，全部可被 `prefers-reduced-motion` 关闭：

- **入场**：路由切换时整页位移 8px 淡入；列表（词砖、结果、首屏义项）以 26ms 错峰跟进，最多 9 档。
- **空间**：联想面板自上而下落入；主题切换用 View Transitions 从点击点径向扩散（Chromium），其余浏览器瞬时切换。
- **触感**：词砖上浮 2px、圆章旋 45°；词形条目左移 2px；按钮下压 1px；复制后图标换勾。
- **等待**：骨架屏高光扫过；分页按钮内嵌旋转环；429 倒计时呼吸；语义进度条保持不确定态，配秒表——不假装知道百分比。

动效规格表见 `docs/INTERACTION.md` §11。
