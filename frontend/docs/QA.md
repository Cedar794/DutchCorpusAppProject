## 3.5 文案层级

第二版把描述性段落压到功能文本：

- 首页删掉 4 栏特性介绍与 3 段说明，只留「词条 / 三条规则 / 三枚口径 note」。
- 结果页删掉引导段，判断依据压成 `best_match = null` 一角 hint；未命中提示从两行长文变成一句「未命中。下列为纠错与近似候选。」
- 词条页的 div 说明改为 6–12 字的注脚（「同名词形已合并，标签为来源」「无记录。」），完整解释移入「数据与方法」与 `docs/`。
- 「数据与方法」由长文改为键值表 + 数据表 + 四行清单。

## 4. 已知限制 / 未覆盖

1. **未接真实后端**：真实 API 尚未公网部署，联调验证全部基于录制回放。`?api=` 切换路径已实现，但没有对真实 8080 服务跑过端到端。
2. **未做真机读屏测试**：ARIA 属性、焦点顺序、标题更新按规范实现，但没有 VoiceOver / NVDA 实测记录。
3. **打印样式**只写了 CSS，未导出 PDF 核对分页效果。
4. **离线包分页**：`afzetten` 只能连续读到 14 / 33（录制仅覆盖 offset 0、7、28），再往后会显示「未录制」；`zijn` 的义项第二页、`ontdekken` 的语料第二页同理。这是录制范围限制，不是前端缺陷。
5. **Safari / Firefox** 未实测；用到的 `color-mix()`、`<dialog>`、`:has` 之外的新特性在近两年版本均可用。
6. 词形搜索框的 `type=search` 在部分浏览器不支持 `setSelectionRange`，已 try/catch 兜底。
